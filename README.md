# Netflix Data Analysis

## Project Overview
This project analyzes Netflix Movies and TV Shows dataset using Python.

## Tools Used
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Movies vs TV Shows Distribution
- Top 10 Highest Rated Movies
- Content Analysis by Country
- Data Cleaning and Exploration

## Key Insights
- Movies are more common than TV Shows on Netflix.
- Certain countries contribute the majority of content.
- Highly rated movies were identified using IMDB ratings.
